# 06 · 使用说明（每天 5 分钟怎么用）

> 打开看板：<http://127.0.0.1:8686> —— 下面按"看什么、怎么解读、怎么做"展开。

---

## 1. 每日 5 分钟流程

1. **收盘后**（最好 16:00 以后，自动更新在交易日 15:45 触发）打开看板；
2. 看「判断规则结果」卡片：
   - 显示 **当前无信号** → 今天什么都不用做；
   - 显示红色/橙色信号 → 按 §3 的对照表行动；
   - 显示 **份额数据积累中（n/5）** → 规则还没生效，继续等；
3. 扫一眼「持仓明细」表里的 **份额日变动** 列——连续多日同向就是趋势在走；
4. 有需要再看「趋势图」：份额曲线抬头（申购进场）或低头（赎回撤退）配合价格位置解读。

## 2. 怎么读规则结果

### 状态机

| 看到什么 | 含义 |
|---|---|
| `warming_up · 份额数据积累中（n/5）` | 部署后需约 5 个同源交易日积累，期间**没有信号是正常的**；若来源显示 tencent，说明当天东财限流降级了 |
| `ok · 当前无信号` | 两条规则均未触发 → **按自己的计划执行**；国家队在场不等于可以放松风控 |
| `ok · BOTTOM_BUY_REF（底部买入参照）` | 规则一触发，见下 |
| `ok · AVOID_CHASE（高位不追/止盈警示）` | 规则二触发，见下 |

### 触发时背后发生了什么（消息里的数字）

- **底部买入参照**：基准ETF单日跌 ≥1.5%（或 5 日 ≥4%），且沪深300系 4 只 ETF 份额当日合计增加 ≥0.8%（或 ≥0.3% 且成交放量 ≥2 倍均量）——这就是"急跌 + 国家队进场"的形态；
- **高位不追/止盈警示**：20 日涨 ≥8%（或价格在近 120 日 90% 分位上方），且份额连续 4 日下降、累计 ≤ -1%——权重股失去边际买家的形态；
- 级别 **strong** 比 **medium** 更极端（信号幅度更深），medium 也要当回事，只是仓位动作更轻。

## 3. 信号 → 操作对照表

| 信号 | 参考动作 | 纪律 |
|---|---|---|
| `BOTTOM_BUY_REF`（strong） | 形态可靠度较高：可启动/加码**分批买入**计划（例如分 2~3 笔） | 单笔仓位预先定死；不加杠杆；跌破信号日低点说明形态证伪 |
| `BOTTOM_BUY_REF`（medium） | 轻仓试错或仅观察次日确认 | 不追第一笔满仓 |
| `AVOID_CHASE`（strong） | **停止新买入**；拥挤/浮盈大的仓位部分止盈 | 不因"还在涨"而违反 |
| `AVOID_CHASE`（medium） | 停止追高，收紧持仓止损位 | 观察后续份额是否继续流出 |
| 无信号 | 按自己的既定计划执行 | 规则是"情绪的锚"，不是日常买卖依据 |

> 两条规则都基于"份额≈国家队行为代理"，能捕捉形态但**不能确证是汇金**，属于概率参照。

## 4. 程序化调用（常用片段）

```bash
# 当前两条规则的结果
curl http://127.0.0.1:8686/api/signals

# 某只ETF近 60 日明细
curl "http://127.0.0.1:8686/api/details?code=510300&limit=60"

# 趋势图存本地
curl -o trend.png "http://127.0.0.1:8686/api/etf/510300/trend.png?days=250"
```

完整的接口说明见 [03-接口文档](03-接口文档.md)；想每天收到通知，可以自己加一个 cron 轮询
`/api/signals`，检测到 `status=="ok"` 且 `signals` 非空时推送。

## 5. 调参指南（config.json → rules）

| 想要… | 调哪个 |
|---|---|
| 信号更少更准（只抓大形态） | 跌幅阈值更负（-2.5）、份额增幅更高（1.2）、赎回累计更深（-2.0） |
| 信号更多更灵敏 | 反向放宽，但噪音会显著增加 |
| 更看重"放量确认" | 降低 `inflow_1d_pct_vol`、提高 `vol_multiple` |

改完执行 `.venv/bin/python update.py --force` 立即按新阈值重算当天。

## 6. FAQ

- **为什么份额曲线只有几个点？** 份额数据自部署日起每日积累，之前的拿不到每日口径；点数少是正常的。
- **周末/节假日怎么没更新？** 只在交易日收盘后更新；服务照常运行，下一交易日自动恢复。
- **来源一会儿 eastmoney 一会儿 tencent？** 东财限流时自动降级；系统自动做了同源隔离，跨源日不会计入信号。
- **信号当天没触发但我觉得市场很像底部？** 工具只认既定阈值形态；自己的判断自行负责，工具负责的是纪律性提醒。
- **换电脑怎么迁移？** 拷贝整个安装目录（含 `data/etf.db`），新机重跑 `install_launchd.sh`。
