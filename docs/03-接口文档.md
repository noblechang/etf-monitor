# 03 · 接口文档

> 基础地址：`http://127.0.0.1:8686`（仅本机可达）
> 所有响应为 JSON（图表接口除外）；中文UTF-8；无鉴权（请勿修改 listen_host 对外暴露）。
> 服务版本随 `GET /api/rules` 等响应头 `server` 可见；当前 v1.1.0。

---

## 1. 端点总览

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/` | 网页看板（HTML，300s 自动刷新） |
| GET | `/api/etfs` | 监控清单 |
| GET | `/api/summary` | 最新一轮汇总（各ETF最新价/份额/规模 + 规则状态） |
| GET | `/api/details` | **每日明细**（客户查询①） |
| GET | `/api/signals` | **两条规则的结果 + 历史信号**（客户查询②） |
| GET | `/api/rules` | 规则定义与阈值 |
| GET | `/api/etf/{code}/trend.png` | **单ETF趋势图**（客户查询③） |
| GET | `/api/chart/combined.png` | 组合汇总图 |
| POST | `/api/update` | 手动触发一轮更新 |

## 2. 端点详情

### 2.1 GET /api/etfs
返回监控标的清单。
```json
[{"code": "510300", "symbol": "sh510300", "secid": "1.510300",
  "name": "沪深300ETF华泰柏瑞", "group": "hs300"}, ...]
```

### 2.2 GET /api/summary
无参数。返回整体状态与每只 ETF 的最新快照。

| 字段 | 说明 |
|---|---|
| updated_at / last_data_date | 最近完整更新时间 / 数据最新交易日 |
| rule_status | 最近一次规则评估结果（结构见 2.4 的 latest_status） |
| etfs[].shares_chg_1d_pct | 份额日变动 %（**仅前后两日同来源时给出**，跨源为 null） |
| etfs[].amount_yi | 成交额（亿；K线日为估算值） |

```json
{"updated_at": "2026-10-04T17:36:55", "last_data_date": "2026-09-30",
 "rule_status": {...},
 "etfs": [{"code": "510300", "name": "沪深300ETF华泰柏瑞", "group": "hs300",
           "date": "2026-09-30", "close": 4.432, "pct_chg": 0.36,
           "amount_yi": 24.1, "shares_yi": 241.2, "scale_yi": 1069.0,
           "shares_chg_1d_pct": null}, ...]}
```

### 2.3 GET /api/details —— 每日明细
| 参数 | 必填 | 说明 |
|---|---|---|
| code | 是 | ETF 代码（见 /api/etfs），未知代码返回 404 |
| start / end | 否 | 日期区间（含端点，格式 YYYY-MM-DD） |
| limit | 否 | 只返回最近 N 条（默认 250） |

```bash
curl "http://127.0.0.1:8686/api/details?code=510300&start=2026-09-01&end=2026-09-30"
```
```json
{"code": "510300", "rows": [
  {"code": "510300", "date": "2026-09-26", "close": 4.41, "pct_chg": -0.09,
   "volume": 184000000.0, "amount": null, "amount_est": 811440000.0,
   "shares": null, "scale": null, "source": null}, ...]}
```
说明：`shares` 仅自部署日起逐日有值；`source` 标识该日份额来源（`eastmoney`/`tencent`，纯K线行为 null）。

### 2.4 GET /api/signals —— 两条规则的结果
| 参数 | 必填 | 说明 |
|---|---|---|
| limit | 否 | 历史信号条数上限（默认 50） |

```json
{"latest_status": {"status": "warming_up",
                   "message": "份额数据积累中（同源 1/5 个交易日，来源 tencent），规则暂不生效",
                   "signals": [], "evidence": {...}},
 "signals": [{"date": "2026-07-08", "rule": "BOTTOM_BUY_REF", "level": "strong",
              "message": "大跌+放量净申购：510300 单日 -1.87%、5日 -4.31%，……",
              "evidence": {"drop_1d_pct": -1.87, "hs300_inflow_1d_pct": 1.12, ...},
              "created_at": "2026-07-08T16:02:11"}]}
```

`latest_status.status` 取值：
| 取值 | 含义 |
|---|---|
| `warming_up` | 份额数据积累不足 5 个同源交易日，规则未生效（`signals` 恒空） |
| `ok` | 已生效；`no_signal=true` 表示当日两条规则均未触发 |
| `no_data` | 库内无任何行情数据（首次启动失败等） |

调用方处理建议：**只消费 `latest_status` 作为当前状态**，`signals` 列表用于回看历史。

### 2.5 GET /api/rules
返回规则配置与基准优先级，便于核对/调参。
```json
{"rules": {"bottom_buy": {"name": "底部买入参照", "drop_1d_pct": -1.5, ...},
           "avoid_chase": {...}},
 "base": ["510300", "510310", "159919", "510050"],
 "note": "阈值可在 config.json 调整后重启/手动触发更新生效"}
```

### 2.6 GET /api/etf/{code}/trend.png —— 单ETF趋势图
| 参数 | 说明 |
|---|---|
| code | 路径参数，未知代码 404 |
| days | 图表天数，默认 120，范围 20~550。120 天版由每日更新预生成；其他天数按需渲染并缓存为 `{code}_d{days}.png` |

三联布局：收盘价+MA20（红虚线=底部买入参照，橙虚线=高位不追警示）/ 成交额柱 / 场内份额。
```bash
curl -o 510300.png "http://127.0.0.1:8686/api/etf/510300/trend.png?days=250"
```
错误：库内该 code 无数据 → 404 `{"detail": "no data yet"}`。

### 2.7 GET /api/chart/combined.png
组合图：基准ETF价格 + 沪深300系合计份额 + 全组合合计份额（信号竖线同上）。

### 2.8 POST /api/update —— 手动触发更新
| 参数 | 说明 |
|---|---|
| force | `true` 强制重跑（忽略"今天已更新"幂等检查） |

立即返回（更新在后台线程执行）：
```json
{"started": true, "tip": "轮询 GET /api/summary 的 updated_at 判断是否完成"}
```
完成后可用 `GET /api/summary` 对比 `updated_at`，或用命令行 `python update.py --force` 直接拿到完整摘要 JSON。

## 3. 错误格式与码

| 码 | 场景 |
|---|---|
| 404 | 未知 code / 无数据 |
| 422 | 参数校验失败（FastAPI 自动） |
| 200 | 成功（含 warming_up 等业务状态——业务异常不影响 HTTP 状态码） |

## 4. 调用者完整示例

```bash
# ① 每日明细：近 60 个交易日
curl "http://127.0.0.1:8686/api/details?code=510300&limit=60"

# ② 两条规则的结果
curl "http://127.0.0.1:8686/api/signals?limit=20"

# ③ 趋势图
curl -o trend.png "http://127.0.0.1:8686/api/etf/510300/trend.png?days=120"

# ④ 组合图
curl -o combined.png http://127.0.0.1:8686/api/chart/combined.png

# ⑤ 触发更新并等待完成
curl -X POST "http://127.0.0.1:8686/api/update?force=true"
```

Python 例：
```python
import requests, time
base = "http://127.0.0.1:8686"
requests.post(f"{base}/api/update?force=true")
while True:
    s = requests.get(f"{base}/api/summary").json()
    if s["updated_at"]: break          # 更新完成后 updated_at 变为今天
    time.sleep(5)
status = requests.get(f"{base}/api/signals").json()["latest_status"]
if status["status"] == "ok":
    for sig in status["signals"]:
        print(sig["date"], sig["rule"], sig["level"], sig["message"])
```
